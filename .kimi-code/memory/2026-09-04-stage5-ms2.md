## 编号 join 算法（Q2 印刷忠实的实现）

- **mathnum 事件 → display 公式**：事件序=源码序（display 不可浮动）；每个 env 按其行结构
  消费事件——per-row env（align/alignat/eqnarray/gather/flalign）逐行：`\nonumber` 行不消费、
  `\tag` 行消费（与源码 tag 文本对拍，event 优先）、`\tag*` 行取源码 tag 文本**不消费**
  （\tag* 无事件，N2 已知限制）；equation/multline 单行消费。env 失配 → 警告 + 该 env 回退
  aux/计数（一次性 resync：下一事件匹配则跳过杂散事件）。多行显示号：连续整数区间
  "3–5"，否则逗号连接 "3,X"。**未编号 display（\[…\]/ starred）永无编号（Q2）**。
- **section**：section 事件（现含 subsubsection）按序 join + aux 对拍（brace-strip）；无事件
  → aux-labeled 或计数（`\appendix` 后一级字母化）。`\paragraph`→ level 4 无号。
- **figure/table**：**`.lot`/`.lof` 优先**——\@writefile 记录恒在 .aux 内（\listof* 从未跑也有），
  真 .lof/.lot 文件存在时覆盖；按源码序 join（同类浮动 LaTeX 保证 FIFO 不换序）。
  **这修掉了 label-before-caption 作者笔误**（2501.17225 的 "Table: phi_org_pole" aux 记
  A.2 但印 A.1 → 取 A.1 + 警告）。无 caption 的 figure/table 无号（印刷忠实，改掉了旧管线的
  一律计数）。回退：aux-labeled → 计数（带 trailing-int 递增与 resync）。
- **xref**：`\ref/\eqref/\autoref/\cref/\pageref` → labelMap（label 挂到块/节，行级 \label
  挂行号）；number 取块的指定号（事件/lot/aux/计数解析后的印刷值）。`\eqref` 文本 "(N)"。
- **cite**：源码出现为主（宏展开后即源码可见）；事件流对拍——先按 (file,line,keys) 精确
  匹配（宏展开产物带调用点位置，所以对得上），失配的按源码行内容分类：无 \cite 且无
  unexpandable 宏 → 移动参数双发丢弃；否则兜底进最近块的 citationsByBlock（脚注 cite、
  table 内手写 caption 文本的 cite 走这条路——设计上它们不产生源码 occurrence）。
- **脚注正文按旧例丢弃**（但其中 cite 经事件兜底进 citationsByBlock，比旧管线多保留链接）。
