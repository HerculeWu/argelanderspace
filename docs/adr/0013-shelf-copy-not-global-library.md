# 文献仓：跨项目复制存取，而非全局 Library

用户常有一批文献在多个项目里反复用，每个项目都要重新添加条目；而 LaTeX 摄入（下载源码、TeX Live 多轮编译）与文本 Doc 转录（Copilot 按页看图）是贵操作。因此引入**文献仓（Shelf）**（[CONTEXT](../../CONTEXT.md)「数据范围」）：属于人的全局数据（[ADR 0007](0007-global-data-scope.md)），用户在项目里显式「加入文献仓」，在别的项目里显式「从文献仓取入」；**两个方向都是复制**，进出之后项目与文献仓互不影响。文献仓只供存取，不是工作区，不能在其中阅读、标注或探索。

本决定局部修订 ADR 0007「本决定不授权全局 Library 复用」一句：授权的是这种复制存取，**仍不授权全局 Library**——Library、标注、Plan、Manuscript 照旧是项目数据，既有项目数据不迁移。

## Considered Options

- **全局 Library / 全局工作区**（一个所有项目共用的文献库）：把属于研究项目的整理状态（标签、笔记、阅读进度、标注）绑在一起，项目不再自包含。否决。
- **取入时引用文献仓里的同一个 Doc**：项目目录不再自包含、拷到别处缺正文；Doc 的全局物理删除和「内容不同 → 整批归档」会跨项目生效，与「项目数据互不共享」冲突。否决，改为复制。
- **重复加入时合并**（Doc 追加、标注追加）：同一 Doc 内容变化后新旧标注如何共存，正是标注契约拒绝的逐条 salvage。否决，改为确认后整条替换。
- **取入时用文献仓的 Doc 覆盖项目里已有的同 id Doc**：会触发整批归档，等于一条新的替换用户数据路径。否决，改为跳过并说明。
- **按标题相同认定「同一篇」**：可能是另一篇论文。否决，只认 DOI、arXiv、OpenAlex 号。

## Consequences

- 标注、论证图、Work 笔记是用户对这篇文献的解读，可能带项目语境：加入时逐条（逐项）选择，**默认不带**；取入时可再取消，默认全取。标签、星标、已读、PDF 阅读位置是项目内状态，不进文献仓；cite key 按目标项目规则重新分配。
- 复制保持 Doc id 与正文字节不变，标注指纹不含项目相关输入，所以带过去的标注在新项目里仍是当前标注；加入时只经服务端标注访问路径读当前标注，归档永不进文献仓。
- 文献仓是多个工作台进程共享的全局数据，写入（加入、替换、删除）在跨进程锁内整次成功或整次不写；取入只读文献仓，写项目数据时沿用项目的并发边界（I013）。具体条文见 [contracts](../contracts.md)。
- 文献仓里的条目可能由较新版本写入：条目带格式版本，看不懂的条目只显示、不取入、不改写。
