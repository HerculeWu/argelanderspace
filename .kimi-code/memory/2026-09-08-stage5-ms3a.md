位置正指向该字符（空格或 %），查源码行该位字符，空白则补空格（fuse/walk.ts
`commentHasPrecedingSpace`，segments/plainText 两路）。回归测试入 tex-fuse 套件。
`a%x\nb` 仍正确连写。
