# 踩坑录（2026-09-01 合并版；工具链/环境/依赖层，长期有效）

## 环境

- **pnpm 只能 `corepack pnpm`**（裸 pnpm 不在 PATH）；node 需 ≥22.13（系统 v24 满足 pnpm 11）。
- **pandoc**：LaTeX 管线与 golden 测试要 astro env 的 pandoc 3.9（`/home/wwu/miniforge3/envs/astro/bin/`）；系统 `/usr/bin/pandoc` 3.1.3 会让 golden 红。**不要把整个 astro bin 前置 PATH**——astro 自带 node v20 会抢先系统 node，pnpm 起不来。用只含 pandoc 的 shim 目录前置（`/tmp/ms1-bin/pandoc` → astro pandoc 的单独 symlink；/tmp 会被系统清理，丢了重建即可）。
- **测试密封**：config 测试 `$XDG_CONFIG_HOME` 指 tmp 密封真实 config；spawn 子进程测试 `HOME=<tmp>` 逼 ADS no-token（`ADS_DEV_KEY=""` 会被忽略、回退到 `~/.ads/dev_key`）；网络类测试全离线（fetchImpl 注入）。
- **web 测试**：web 用 vitest ^3（vitest 4 要 vite 6+，web 仍 vite 5；其余包 vitest 4 互不干扰）；vitest.config.ts 独立于 vite.config.ts（不载 react 插件）；happy-dom 下读文件用 `node:url` 的 `fileURLToPath`（全局 URL 是 happy-dom 的，node fs 拒收）；IntersectionObserver 需 stub（一律报 intersecting）。
- **biome**：packages/web 有 legacy override（formatter/organizeImports/a11y 等关闭）——不要对前端旧文件 `--write` 重排；新代码保持 biome-clean。真实出版商 HTML 夹具经 `files.includes` 否定项排除（biome 报 parse 级错误，override 关不掉）。

## mupdf（npm WASM 包）

- **`onChar` 截断非 BMP 码点**（上游 bug：`String.fromCharCode` 只留低 16 位，U+1D441→U+D441 谚文）。已在 infra `pdf/text-provider.ts::clippedTextOf` 绕开（asJSON 行文本按位置 zip 回 walk 的 quad 流），有非 BMP 钉测。**mupdf 升级后必须复测此绕开**。
- 裁剪取字 = `toStructuredText().walk({onChar})` + 字符 quad 中心在 rect 内（与 PyMuPDF `clip=` 逐字节一致）；`asText()`/`pageText` 全保真不受影响。
- 链接：`isExternal()` 判别；mupdf 给 GoToR 加 `file:` scheme；named dest `#nameddest=` 剥前缀 + `decodeURIComponent`；dest 坐标已是左上原点（**勿再 y-flip**）。
- 内存纪律：page/stext/pixmap 用完 `.destroy()`（WASM 堆不自动回收）。
- **打包必须 external**（双因：WASM loader 用 `import.meta.url` 定位 .wasm，inline 必挂；mupdf 是 AGPL-3.0，不进 MIT tarball）。版本精确锁 1.28.0。

## 打包/分发（packages/app）

- **esbuild CJS→ESM 坑**：`safer-buffer`（cheerio→iconv-lite 链）用 eval 藏 `require("buffer")`，esbuild 静态改写不了；tsup `shims:true` 只注入 `__filename/__dirname`——必须自加 banner 注入 `createRequire`（esbuild 的 `__require` shim 检测到顶层 require 存在即用它）。
- web-dist 解析顺序：`<bundle文件>/web`（import.meta 相对，packed 布局）→ `<cwd>/packages/web/dist`（repo dev）。
- 版本号两处手工对齐：cli `.version("…")` ↔ app package.json（无单一来源）。
- config.toml：smol-toml；`loadConfigFile` 每次现读磁盘无缓存；未知键忽略（前向兼容）；已知键类型错报错点名键名；**出错消息从不回显值**。

## 数据/兼容层（仍在代码里生效，别当冗余清理）

- core 的 `pyOr/pyTruthy/pyRe`（Python 真值语义、`\b` Unicode 感知）是有意的防御性语义移植，注释有记录，勿"优化"掉。
- `core/src/acquire/latexenc-data.ts` 是机械提取的 2394 对替换表（bibtexparser 1.4.4），**勿手改**；`@retorquere/bibtex-parser` 10.0.1 发布时没带 .d.ts，本地最小声明在 `core/src/types/bibtex-parser.d.ts`。
- sources 缓存键 = `sha1(path + "?" + json.dumps(params, sort_keys=True))` 字节级复现 Python（`infra/lib/pyjson.ts`，含 ensure_ascii/分隔符细节）——`literatures/library/cache/` 存量缓存直接复用靠它。
- `statSync(p).mtimeNs` 不存在于普通 stats——必须 `statSync(p, {bigint:true})`（server PaperCache、watch.ts 指纹都靠它）。
- **HTML 管线**（将隔离到 `ocr-features`）：cheerio/htmlparser2/parse5 都会在块级子元素前自动闭合 `<p>`，Python html.parser 不会——`core pipelines/html/bs4-parser.ts` 手写流式树构建器复现 bs4 语义（不自闭、void 元素不压栈、`_popToTag`、相邻文本合并），是当年 golden 0-diff 的关键。改动它之前先读 git 历史里的 `2026-08-26-m3c-html-pipeline.md`。
