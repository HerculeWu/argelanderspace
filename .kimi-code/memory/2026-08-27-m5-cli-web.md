## CLI（packages/cli）

- 入口 `src/bin.ts`（shebang）→ `src/program.ts` `buildProgram()`；`src/detect.ts`（源自动检测）、`src/summary.ts`（ingest summary + acquire 计划表格式化，纯函数可测）。
- **源检测顺序**（同 `cli.py`）：arXiv id/前缀/URL → latex；DOI/http(s) URL → html；**本地已存在的 .tex/目录/tarball → latex（新增，补上 Python help 文本承诺但未实现的路由——Python 里 local .tex 会掉进 PDF 路径报错）**；其余 → pdf。
- flag 映射：commander 的 `--ocr`+`--no-ocr` 双定义天然给出 undefined/true/false 三态 → `isOcr null/true/false`；`--no-assets/--no-subpages/--no-cache/--no-formula/--no-table/--no-links` 取反；`--reuse` 是 **Python 里的死 flag**（默认即复用），bug-for-bug 保留为 no-op；`--fresh` → `useMineruCache:false`。
- 坑：**summary 的 stats 在 `documentToJson()` 序列化时才计算**（管线返回的 Document 无 stats 键）——必须先序列化再读 stats（同 Python `doc.to_dict()`）。
- `--data-dir` 全局可配（子命令前后位置都行），解析链 flag > `ARGELANDERSPACE_DATA_DIR` > `./data`；ingest out-root 默认 `<dataDir>/output`。`serve` 只转发显式传了的 flag 给 `startServer(argv)`，保住 server 的解析链；SIGINT/SIGTERM → `srv.close()` 干净退出。
- 冒烟测试（`tests/smoke.test.ts`，打 **dist/bin.js**，pretest 用 `tsc -p tsconfig.build.json`——此机 pnpm 只能 corepack 调，脚本里裸 `pnpm` 不在 PATH）：latex fixture ingest 出 summary + 落盘 JSON；`library build --offline` 出 summary JSON + 写 library.json；serve 临时端口 boot + `/api/papers` + SIGTERM exit 0。**子进程给 `HOME=<tmp>` 逼 ADS no-token**（本机 ~/.ads/dev_key 有真 token，`ADS_DEV_KEY=""` 会被忽略回退到文件）。
- acquire 计划表与 Python **逐字节一致**（`references.bib` 33 works 全表 diff 为空；截断 bib 会因解析器宽容度差 1 条，不算 bug）。
