## mathnum 插桩的实证结论（含审查修正，本机 TeX Live 2023/Debian, latexmk 4.83 实测）

补丁点（本机 TeX Live 2023/Debian, latexmk 4.83 实测）：

- **amsmath 加载时只 patch `\tagform@`**：amsmath 重定义了 `\@eqnnum` 使其内部调用
  `\tagform@`（amsmath.sty:1221-1224），equation/eqnarray/align/gather/multline/flalign
  全部经 `\tagform@` 排号——单补丁点全覆盖。patch 两个会双发事件。
- **amsmath 缺席时 patch 内核 `\@eqnnum`**（latex.ltx:12698）：equation/eqnarray 覆盖。
- `\tagform@` 的三个坑（全部实测复现并有对策）：
  1. **`\eqref` 也调用它**（amsmath.sty:1150）→ `\@currenvir` 环境白名单
     （equation/align/gather/multline/flalign/alignat/eqnarray）挡掉散文中的 \eqref；
     **显示环境内的 `\eqref`/含宏 `\tag` 仍会漏过白名单**（N1）→ 事件 parser 丢弃
     number 含控制序列（反斜杠）的 mathnum 事件 + 计数 warning。
  2. **测量 pass 会重复调用**（align/gather/multline 先量后排）→ `\ifmeasuring@` 挡掉。
  3. **hyperref 给 `\tag` 值包 `\Hy@make@anchor`**（hyperref.sty:7767-7777 重定义
     `\make@df@tag@@@` → `\tagform@{\Hy@make@anchor X}`），其 `\Hy@raisedlink` 在
     `\protected@edef` 里爆炸（B1：插桩编译 exit 12 → 静默 fallback → 事件全丢）。
     修复：捕获在 group 内进行并 `\let\Hy@make@anchor\@empty`，`\protected@xdef`
     导出；`\tag{B}` 捕获恰为 `B`（hyperref fixture 回归测试锁死）。
- 编号值取 **`\tagform@` 的参数**：普通行 = `\theequation` 真值；`\tag{M1}` = 字面
  tag 文本（counter 不前进）。subequations → "3a"/"3b" 实测正确。
- **行号语义**：amsmath 多行环境（align/gather/multline）的每行事件报告的是
  **环境结束行**（`\end{align}` 行）；eqnarray/equation 报告**精确行号**。
  事件在环境内的顺序 = 行序，MS2 融合按"环境块 + 序"锚定。
- **零干扰实测**：插桩 vs 干净编译 `.aux` 逐字节相同（battery fixture，成形测试）。
  注意措辞：这只证明 counter/label/.aux 恒等；whatsit 在极端构造下理论上可影响断行——
  不做"零排版副作用"全称断言。
- **事件写出顺序 = shipout 顺序**（`\protected@write` 延迟）：浮动体内的 \label 事件
  会迟到。融合层勿假设严格源码序。
- **事件 id 可有缺口**（N1 文档化）：id 在 TeX 事件时分配；被丢弃的试探排版盒
  （amsmath equation 会试排）里的 whatsit 烧掉 id 但不上船；parser 丢弃的伪事件也留
  缺口。消费方不得假设每族 id 连续。
- **`\tag*{X}` 不捕获**（N2 已知限制）：amsmath starred tag 走 `\maketag@@@` 绕过
  `\tagform@`；刻意不扩补丁面。公式印了号而我们无事件 → MS2 编号兜底（.aux+源码数数）。
- **`file` 字段（N3）**：每个事件带 `"file":"\CurrentFile"`。实测：主文件与
  `\input`/`\include` 子文件解析正确（battery 的 child.tex 三种事件全对）；但
  **生成文件回读期间（\listoffigures 等走 `\@starttoc` → `\@input` → 原始 \@@input，
  无 file-hook 簿记，latex.ltx:7930/14279）`\CurrentFile` 滞留主文件名**——
  `\cite` 在 `\caption` + `\listoffigures` 会双发 cite 事件，第二个的 line 指向 .lof
  行号、file 仍是 main.tex。**file 对 MS2 多文件行号对齐可靠，对"移动参数去重"不可靠**；
  后者只能靠 MS2 融合时按源码行内容防御性过滤。
- 真实类验证（非冻结，/tmp 一次性）：2501.17225（aa.cls + natbib + hyperref + amsmath，
  24 张图换成真 PDF 后）插桩编译 pdflatex 3.6s 零 warning，260 事件
  （157 cite 含 8-key 多引 / 55 label / 36 section / 12 mathnum）。
  **另：hyperref 回归 fixture（adv 电池：amsmath+hyperref+natbib[numbers]）已冻结**，覆盖
  \tag(B)/subequations/aligned-in-equation/全 nonumber align/散文 \eqref。

## 工程坑

- **expl3 不能塞进宏体**：`\ExplSyntaxOn` 在 `\def` 体内无效（catcode 已冻结）。
  环境白名单成员判定要在顶层 ExplSyntaxOn 区定义零参包装再 `cs_new_eq` 出纯字母别名
  （`argelanderIfMathenvTF`）。`\clist_if_in:NnTF` 是 4 参（clist, item, T, F），
  包装成 2 参用。
- **.sty 资产随包分发**：`packages/infra/src/tex/argelander.sty` 经
  `new URL("./argelander.sty", import.meta.url)` 读取；infra build script 已加
  `node -e copyFileSync` 拷进 `dist/tex/`。**MS3/MS4 检查点**：`packages/app` 的 tsup
  把 core+infra 内联成单文件 bundle，`import.meta.url` 指向 `app/dist/`——必须把
  argelander.sty 拷到 bundle 旁（参照 mupdf wasm 的 external 说明）。缺失时按设计降级为
  干净编译 + warning（不硬失败），所以 bundle 缺资产不会崩、只会丢事件。
- **-recorder 只传给引擎**：latexmk 不给 bibtex 加 -recorder，.fls 里没有 .bib
  （只有引擎 INPUT 的 .bbl）。MS2 要 .bib 需另寻 `\bibliography{...}`（源扫描）。
- **.fls 会混入插桩内部文件**（`__argelander_wrap.tex`/`argelander.sty`）与 PWD 的
  tmpdir 绝对路径；MS2 需过滤。
- **timeout 不重试引擎**（\loop 类死循环与引擎无关，重试纯浪费）：任一 attempt 超时即报
  compile-timeout。进程组 SIGKILL（detached spawn + kill(-pid)），否则 latexmk 死了
  pdflatex 还在跑。
- 编译 flags 只有 `-interaction=nonstopmode -recorder`（不加 `-no-shell-escape`：会弄断
  epstopdf 之类受限 shell 白名单，导致本可编译的论文失败；minted/`\write18` 靠预扫描拒）。
  残余暴露面 = TeX Live 默认受限 shell 白名单（repstopdf 等），单用户工作台可接受。
- wrapper 写在 **main 同目录**（`\input{<basename>}`），latexmk cwd = 该目录——子目录
  main 的相对 \input 不断链。
- 降级成功（干净 fallback / 事件流缺失）保留 `.log` 进 outDir；完全成功丢 `.log`（Q5）。
