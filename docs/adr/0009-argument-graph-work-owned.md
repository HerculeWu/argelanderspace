# 论证图属于 Work，出处只作参考

论证图是用户或 agent 对一篇文献论证结构的整理，每个 Work 至多一张。它属于 Work 而不是 Doc：整理的对象是这篇文献的论证，不是某一份正文文件，用户把它看作 Work 名下一份独立的新材料。论证的出处只是回原文核对用的参考，可带跳转目标，但不随正文变化受保护。

这与文档标注的规则相反。标注绑定 Doc 的内容指纹，正文替换即整批归档（[ADR 0003](0003-annotation-epochs.md)）；论证图不参与指纹、归档或 Doc 的全局物理删除。

## Considered Options

- 论证图属于 Doc，出处使用该 Doc 的结构寻址并随指纹失效：出处始终可信，但同一篇文献的多个 Doc 会各有一张图，重摄入会让整张图归档，而论证本身并没有变。

## Consequences

- 论证图不是 Doc：不进入 Work 的 Doc 关联，不能设为主 Doc，不带文档标注。没有正文的 Work 也可以有论证图。
- 删除或替换 Doc 不改动论证图；出处的跳转目标失效时只剩显示文字，不报错、不校验、不自动修复。一张图里的出处可以指向同一 Work 的不同 Doc。
- 存储允许环。环、到不了 End 论证的论证等问题由论证审计从图现算，不落盘；发现结构差的论文是这项能力的用途之一，因此不能在写入时拒绝带环的图。
- Work 被合并时论证图要跟随处理，因为每个 Work 至多一张；规则见 [contracts](../contracts.md)。

来源：2026-10-11 至 10-12 论证图设计访谈，用户对第一轮 Q1、Q4 与第二轮 Q1–Q4 的明确答复。本决定规定设计方向；能力已按此实现（数据层、读写接口、视图、手动编辑、Work 合并跟随、CLI、Copilot 工具与确认卡，2026-10-12 工程核查），机制见 [argument-graph](../argument-graph.md)，用户终验于 2026-10-13 通过。
