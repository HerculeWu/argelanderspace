# 通过可读文本接入共享 IR 与流式阅读

新增面向用户和 agent 的可读文本输入到 IR 的转换方向，使从 PDF 转录的正文获得与 LaTeX Reader 一样的流式阅读能力。现有 LaTeX → IR 和 IR → agent 文本路线继续存在；新增路线直接从文本构建 IR，不要求 agent 先生成整篇 LaTeX 源码。

PDF 转录是用户可手工完成、也可交给多模态 agent 的任务，通过 skill 或 instruction 指导；本轮不为它另设转换模型选择或独立自动 AI 转换管线。这一选择遵循 [UI 能力对等](0005-copilot-ui-parity.md)：可手工完成的文本输入能力也是工作台需要提供的入口。

## Consequences

- 目标包括共享 Reader 阅读，不止供 agent 检索或理解的中间文本。
- 现有 agent Markdown 是阅读输出，有省略与清洗，不能假定它是无损的 IR 序列化。新增输入采用 Markdown、必要结构标记和图片资产，在现有 agent 阅读记法基础上补齐完整表格、参考文献与定位信息，公式使用数学语法；具体语法仍需设计，既有冻结输出不改。
- 为 Doc 提供文本源编辑与 Reader 预览，支持导入、粘贴、编辑、校验和生成；用户和 agent 使用相同操作。此入口处理文献正文，与独立 Manuscript 的 Writer 分开。
- 文本源自动保存，点击“生成”才更新 Reader。生成失败保留已保存的输入和上一次成功的阅读内容；自动保存不隐式触发正文替换。
- PDF 转录结果创建为同一 Work 下的独立文本 Doc，记录来源 PDF；原 PDF 的标注与阅读位置保留，文本 Doc 使用独立标注。
- 回到来源 PDF 只需文件级定位。本轮不要求来源页码、区域或逐字符映射，不建设精细回源机制；此范围不影响文本 Doc 内部供 Reader 使用的章节、公式等结构寻址。
- 本决定补充 [ADR 0002](0002-compiled-ir.md) 的新输入方向，不改变 LaTeX 编译真值、编译失败行为或 Writer 管线。
- 文本 Doc 重新生成时的标注处理与确认交互仍需细化。原 PDF、既有标注和阅读位置按 [完整契约](../contracts.md) 保全；本决定不授权原件替换、隐式迁移或重绑。
- 多模态模型可以读取原 PDF 页图，结合可提取文字完成转录。页面内容范围遵循 [ADR 0005](0005-copilot-ui-parity.md) 的完整滚动内容决定，覆盖同一 PDF 的全部页面；原页图是文献材料，工作台界面仍提供结构化上下文。具体传输、分段与容量处理仍需设计，不能把仅收到的可见页称作全文。
